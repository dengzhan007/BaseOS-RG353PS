bootlogo.bmp —— 开机画面说明
================================

这个文件夹里放什么
------------------
把你想在开机时显示的图片命名为 bootlogo.bmp，放在本文件夹里。
开机时系统会在数据分区挂载后读取并显示它。

如果文件不存在、或者格式不符合下面的要求，系统会安静地跳过，
继续用默认画面开机，不会报错，也不影响启动。

格式要求（必须全部满足，否则不会被加载）
----------------------------------------
  文件格式 : BMP（Windows 位图），不是 PNG、JPG、WEBP
  色彩深度 : 24 位（R/G/B 各 8 位），不接受 32 位带透明通道
  压缩方式 : 不压缩 —— BI_RGB，文件头 compression 字段为 0
             （RLE 压缩的 BMP 不会被加载）
  调色板   : 无（24 位不需要调色板）
  分辨率   : 建议 640 × 480，与屏幕一致
             其他尺寸不会报错，会被拉伸铺满整个屏幕，可能变形
  文件大小 : 640 × 480 × 3 + 54 字节 ≈ 900 KB
  文件头   : 标准 54 字节 BMP 文件头

怎么生成 24 位未压缩 BMP
------------------------
  Windows 画图
      打开图片 → 文件 → 另存为 → BMP 图片
      保存类型选 “24 位位图 (*.bmp;*.dib)”

  Photoshop
      图像 → 模式 → RGB 颜色
      文件 → 存储为 → BMP → 高级模式 → 24 位，不要勾选 RLE 压缩

  GIMP
      图像 → 模式 → RGB
      文件 → 导出为 → 文件名写 bootlogo.bmp → 兼容性选项里选 “不压缩”

  ImageMagick（命令行，最省事）
      convert 原图.jpg -resize 640x480! -type TrueColor BMP3:bootlogo.bmp
      其中 BMP3 就是 24 位未压缩 BMP3 格式

  在线转换工具
      选择输出格式 BMP，并把位深设为 24 位、压缩设为无

换图之后
--------
文件放好后直接重启即可生效，不需要重新刷机，也不需要做系统升级。

注意事项
--------
  - 文件名必须正好是 bootlogo.bmp（全小写，注意扩展名不要变成 .bmp.bmp）
  - 建议保留一份原图备份，方便以后调整
  - 本说明文件如果被删除，下次开机时会自动放回，不必在意
  - 图片内容建议避免大面积纯白，以免在暗环境下显得刺眼

技术细节（给排查问题用）
------------------------
系统里的 fbsplash 只接受最简单的 BMP3 形式，判断条件写在
src/fbsplash.c 的 draw_custom_bmp() 里，逐条对应：

  h[0..1] == "BM"                 文件签名
  bmp_le32(h + 14) >= 40          DIB 头大小，必须至少 40（BITMAPINFOHEADER）
  h[26..27] == 1                  平面数必须为 1
  h[28..29] == 24                 位深必须为 24
  bmp_le32(h + 30) == 0           压缩方式必须为 0（BI_RGB）
  bmp_le32(h + 10) >= 54          像素数据偏移不能小于 54
  宽、高 <= 8192                  过大的图片会被拒绝，避免拖慢开机

任何一条不满足，函数直接返回 0，画面保持默认，日志里不会有错误。
